ZUPA · Lignes de bus

Récupère les lignes de bus SOTRA d'Abidjan publiées sur OpenStreetMap, avec les coordonnées de chaque arrêt, et produit le fichier www/data/bus.js de ZUPA. Les gbakas et woro-woros sont ignorés.

1Télécharger les lignes depuis OpenStreetMap

Nécessite une connexion internet. Le téléchargement prend en général 20 à 60 secondes.

2Choisir le fichier actuel bus.js

Sélectionnez www/data/bus.js du projet ZUPA. Les lignes actuelles sont conservées, celles qui existent aussi sur OpenStreetMap sont mises à jour (sans changer leur nom, pour garder les arrêts ajoutés par les utilisateurs), et les nouvelles sont ajoutées.

3Récupérer le résultat

      Remplacez www/data/bus.js dans le dépôt GitHub par ce fichier : l'APK est recompilé automatiquement.

      Données © contributeurs OpenStreetMap, licence ODbL. Les lignes incomplètes (moins de deux arrêts nommés), en construction, ainsi que les gbakas et woro-woros sont ignorés.
