# PDF des pharmacies de garde (secours)

ZUPA récupère chaque jour, automatiquement, le PDF « Tour de garde » publié par l'UNPPCI sur https://www.unppci.org/.

Si ce téléchargement automatique ne fonctionne plus (changement du site), déposez ici le PDF du mois
(bouton « Add file › Upload files » sur GitHub) : il est lu à la prochaine exécution du traitement
« Pharmacies de garde » (onglet Actions), qui se lance aussi dès qu'un PDF est déposé.

Seul le PDF d'Abidjan est utile (pas celui de l'intérieur du pays). Les anciens PDF peuvent être supprimés.
